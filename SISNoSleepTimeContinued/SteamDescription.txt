[h2]What is this?[/h2]
This mod disables or customizes sleep needs in the game or. By the default behaviour, only your community has their sleep disabled, but you can change this in the settings.

If you would rather customize sleep needs instead of disabling them entirely, set [b]MinDaysSleepDeprivationToSleep[/b] to a value above 0, and configure [b]SleepRecoverRateMultiplier[/b] and [b]SleepDeprivationRateMultiplier[/b] to your liking.

Set [b]MinDaysSleepDeprivationToSleep[/b] between 0 and 7. 0 disables sleeps needs, 0.75 results in the same sleeping behavior as the base game, and 7 will result in characters staying awake until they die of sleep deprivation.

[b]Can be added to current saves.[/b]

[b]Not tested in coop.[/b]

[h2]Settings[/h2]
The settings file can be found in the mod's folder under "Settings_NoSleepTime.xml".
[list]
[*] (New) LoggingEnabled. Enables writing debug messages to Log_NoSleepTimeContinued.txt. (default false)
[*] (New) EnabledForPlayer. Enables the mod for the player character. (default true)
[*] (New) EnabledForPlayerCommunity. Enables writing debug messages to Log_NoSleepTimeContinued.txt. (default false)
[*] EnabledForNonPlayableCharacters. Whether characters (humans) from other communities will have their sleep needs deactivated. (default false). 
[*] EnabledForAnimals. Whether animals will have their sleep needs deactivated. (default false)
[*] (New) MinDaysSleepDeprivationToSleep. Sets the minimum amount of deprivation a character must have to go to sleep. If set greater than 0, sleep needs are enabled and use the custom settings below (default 0.0)
[*] (New) SleepRecoverRateMultiplier. Multiplies the speed at which sleep deprivation recovers while sleeping. (default 1.0)
[*] (New) SleepDeprivationRateMultiplier. Multiplies the speed at which sleep deprivation increases while awake. (default 1.0)
[/list]
