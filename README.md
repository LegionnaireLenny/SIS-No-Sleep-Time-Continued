## SIS-No-Sleep-Time-Continued

This is an update to SweetCaptn's mod, SIS No Sleep Time https://steamcommunity.com/workshop/filedetails/?id=3336749898, that fixes a couple issues. This mod replaces the original mod, so do not use them together. This was tested on the publicbeta version.

## Changelog
#### Version 1.2.0
- Added setting to change the minimum sleep deprivation at which characters will sleep
- Added setting to change how fast sleep deprivation recovers
- Added setting to change how fast sleep deprivation builds up
- Added feature toggle settings for the player and player community
- Old log file is deleted when loading a save

#### Version 1.1.0
- Fixed checks for getting/setting sleep deprivation (i.e. the mod works now)
- Fixed incorrect assembly info
- Fixed logging
